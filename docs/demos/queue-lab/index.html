一家虚构咖啡店 · 离线排队实验

平均做得完，
为什么还在等？

每小时来 54 人，制作能力每小时 60 杯。看似有余量，但如果顾客集中到达，前面的人还没做完，后面的人就只能排队。

本页全部是合成条件与确定性计算，不是真实门店数据，也不是经营成效预测。固定 81 位顾客，每人一杯；观察窗口为 90 分钟，计算会继续到最后一杯完成。

先看整条路，再放大制作台

到店→收银排队 / 点单付款→制作前等待 → 制作→叫号 / 取餐

设定有一名收银、一名制作者。本实验只模拟绿色部分：一名制作者、一个服务台、先到先做；第一杯可在第 0 分钟开始，制作不间断、不并行、不插单。

为隔离到达节奏的影响，暂把“到店”视为“订单立刻进入制作队列”，收银和取餐耗时按零处理。现实里，收银可能延迟或成批释放订单，制作也可能受设备、补料与返工影响。

这里的等待，是进入制作队列到开始制作的时间。到店到取餐还包括收银排队、点单付款、制作本身和交付等待，不能用本页数字直接代替。

同样的 81 人，换一种到达节奏

“均匀”预设把人分散在 90 分钟；“集中”预设把人压进前 30 分钟。两者都按固定间隔到达，没有随机数。两个预设都会把每杯制作时间重置为 60 秒。

队列是一笔还没还完的时间债

90 分钟共来 81 人，平均到达率是 81 ÷ 1.5 = 54 人/小时。每杯 60 秒的制作能力是 60 杯/小时。81 杯需要 81 分钟劳动，虽然小于 90 分钟，但空闲能力不能提前把未来顾客的咖啡做完，也不能让已经等待的人回到过去。

在 90 分钟均匀到达时，间隔为 90/81 分钟，约 66.67 秒，大于制作所需的 60 秒；每位顾客到达时服务台已空闲，所以等待为零。这是理想的固定间隔结果，并不代表真实门店在 90% 平均负荷下也不会排队。

集中在前 30 分钟时，间隔只剩 30/81 分钟，约 22.22 秒；这段时间的到达率为 162 人/小时。一杯还没完成，下一位已经来了，等待会逐人累积。第 30 分钟之后没有新客，制作台继续工作，才能消化早先的积压。

令 aᵢ 为到达时间，bᵢ 为开始制作，fᵢ 为完成，s = 每杯秒数 / 60（以下单位均为分钟）。
aᵢ = (i−1)T / 81
b₁ = a₁；bᵢ = max(aᵢ, fᵢ₋₁)
fᵢ = bᵢ + s；wᵢ = bᵢ − aᵢ
平均等待 = Σwᵢ / 81

max 的含义很直接：顾客来了，并且前一杯做完了，才轮得到这一杯。设到达间隔 d = T/81，则本模型还可化简为：

wᵢ = (i−1) max(0, s−d)
平均等待 = 40 max(0, s−d)
最长等待 = 80 max(0, s−d)
最后完成 = 80 max(d, s) + s

没有等待的边界是 s ≤ d，即每杯秒数 ≤ 60T/81；相等时恰好衔接。T = 30 时要每杯不超过约 22.22 秒才能完全不等，已经超出本页 40–100 秒的调节范围。把 60 秒降到 40 秒也只能减轻集中到达的等待。

每多来一位，等待增加 1 − 30/81 ≈ 0.630 分钟。于是最长等待约 50.37 分钟，平均为其一半，约 25.19 分钟。最后一位从到达至制作完成约 51.37 分钟，其中 1 分钟是在制作，不能全叫作“等待”。

图的面积也能复核：每人在等待期间为队列贡献一条“高度为 1、宽度为等待时间”的小带，合起来就是曲线下的面积。因此 排队曲线面积 = 全部等待时间；除以 81 就是平均等待。这里使用完整排空过程，不把第 90 分钟之后的队列裁掉。

一份可讨论的早高峰改善初案

先问“人为什么在同一时段到”，再问“每杯时间花在哪”。仅凭每日或每小时总量，看不到几分钟内的供需缺口。以下是待验证的建议，任何改善数字都只是本模型的情景计算。

把到达分散后，最后完成时间可能更晚，但顾客个人等待更短。最后完成于几点、队列多长、顾客等多久，是不同的问题。

  1. 先画出实际高峰。若将来用于真实店，连续几个可比早晨记录到店、点单完成、开始制作、制作完成、取餐五个时间点；按 5 分钟看到达数，同时记录杯型、返工、补料、缺员。分别计算制作前等待与到店到取餐时间，保留平均、较高分位和最长值。
  2. 先试一个可逆的小改动。若集中到达是主因，可试自愿分时预约、明确取餐时段与容量上限。预点单本身只会省点单时间，若大家仍在同一刻取餐，制作积压可能仍在。不能假定顾客一定愿意错峰，也不要把等待藏到系统里。
  3. 针对制作中的耗时试改。若制作持续忙碌，可在高峰前备好杯盖与原料、减少寻找和交叉走动，试验适当精简高峰菜单。实际计时确认质量、卫生和员工负担；60 秒变为 40 秒只是假设，不能直接写进收益承诺。
  4. 证据支持后再考虑增援。临时支援补料、清洁或交付，可能释放制作者时间；增加制作者则要确认咖啡机、工作台和动作能并行。两个人不自动等于双倍能力。此页仍是一台模型，没有计算加人收益或成本。
  5. 用可比条件判断是否保留。一次只改一个主要因素，比较相近到达量、到达节奏和菜单组合的早晨。事先约定可接受的等待目标，连同端到端取餐时间、错单返工、人工成本与员工负担一起检查；若瓶颈转到收银或取餐，就补测并调整整条流程。

本实验不含收银服务、设备争用、多杯订单、随机到达与制作波动、休息补料、缺货返工、顾客放弃、优先单和取餐拥堵。平均到达率小于平均能力，只是长期承载判断的一部分，不能保证短时无队列；若需求长期超过能力，积压还会持续增长。
